\chapter{INFRAESTRUCTURA Y RECURSOS}

\section{Infraestructura tecnológica}
La plataforma web se desarrollará bajo una arquitectura cliente-servidor moderna, escalable y 
desplegable tanto en entornos cloud como en infraestructura local. Para el alojamiento definitivo 
se contemplan dos escenarios: (1) uso de servicios cloud como AWS (Amazon Web Services), Google 
Cloud Platform o Microsoft Azure, lo cual garantiza alta disponibilidad, escalabilidad elástica y 
reducción de costos de mantenimiento; (2) en caso de preferencia institucional, se realizará el 
despliegue en los servidores Linux del Data Center de la UNSAAC, bajo la supervisión de la Oficina 
de Tecnologías de la Información (OTI). El stack tecnológico propuesto incluye: backend desarrollado 
con Node.js (Express) o Python (FastAPI/Django), base de datos relacional PostgreSQL por su robustez 
transaccional, autenticación mediante JWT (JSON Web Tokens), y frontend responsive construido con 
React.js o Vue.js. Adicionalmente, se utilizará un servidor Nginx como proxy inverso y gestor de 
peticiones, y Docker para la contenerización de los servicios, facilitando el despliegue y la replicación 
del entorno.

\section{Recursos humanos}
El recurso humano necesario para llevar a cabo el proyecto está conformado por  estudiantes 
avanzados con perfiles técnicos específicos. El equipo central incluye: desarrolladores fullstack 
(encargados del backend, lógica de negocio e integración de APIs), diseñador UX/UI (responsable de 
la experiencia de usuario y prototipado de interfaces), analista de sistemas / QA (encargado de las 
pruebas de calidad, carga y seguridad), recursos y comunicación con los stakeholders. Todos los 
miembros poseen formación en Ingeniería Informática, Ingeniería de Sistemas o afines, con experiencia en 
desarrollo web y trabajo colaborativo bajo metodologías ágiles.

\section{Recursos materiales}
Los recursos materiales contemplan tanto equipos de cómputo como herramientas de software y materiales de 
oficina. En cuanto a hardware, se requiere un mínimo de cinco (5) computadoras portátiles con procesador 
Intel i5 o superior, 16 GB de RAM y almacenamiento SSD de 256 GB para las tareas de desarrollo, pruebas 
locales y diseño. Adicionalmente, se necesitará un servidor de pruebas (físico o virtual) con al menos 8 
núcleos de CPU, 32 GB de RAM y 500 GB de almacenamiento para alojar las bases de datos y servicios durante 
la fase de integración. En el plano de software, se utilizarán herramientas de control de versiones (Git 
con repositorio en GitHub o GitLab), entornos de desarrollo integrado (Visual Studio Code, IntelliJ), software 
de modelado de bases de datos (DBeaver, pgModeler), herramientas de diseño (Figma para prototipado), y suites 
de ofimática para la documentación. Finalmente, se consideran materiales de oficina como cuadernos de bitácora, 
pizarras para planificación, y suministros para las reuniones de coordinación y presentaciones.
